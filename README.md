# 📊 AI Data Analyst Agent: KPI & Forecasting Dashboard

An intelligent data analysis agent built with **Streamlit** and **Google Gemini 3.1 Flash**. This agent allows users to upload raw CSV/JSON data and interact with it using natural language to extract KPIs, perform Exploratory Data Analysis (EDA), and generate future forecasts.

## 🚀 Features
* **Natural Language Querying:** Ask questions about your data in plain English (or Hindi-influenced English).
* **Automated EDA:** Instant summaries of data distributions, missing values, and schema.
* **Dynamic KPI Extraction:** Real-time calculation of revenue, conversion rates, and volume.
* **Time-Series Insights:** Automated "Peak Hour" detection and Heatmap generation using Seaborn.
* **AI Forecasting:** Predictive modeling for the next 7 days of sales/activity.
* **Multi-Modality:** Supports both text-based insights and visual charts (Bar, Line, Heatmaps).
* **Localized Formatting:** Specifically optimized for Indian markets with ₹ (INR) currency support.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **LLM Engine:** Google Gemini 3.1 Flash (Generative AI)
* **Data Processing:** Pandas, Numpy
* **Visualization:** Matplotlib, Seaborn
* **Agent Logic:** Gemini "Code Execution" Tooling
